2. Toplanan Bilgiler

Aklımda uygulaması aşağıdaki bilgileri toplayabilir:

  • Ruh hali bilgisi

3. Yapay Zeka Özelliği

Aklımda uygulaması yapay zeka özelliği için aşağıdaki servisleri kullanır:

  • Groq API
  • OpenAI (gerektiğinde)

Yapay zeka özelliği kullanıldığında günlük metniniz analiz için gönderilebilir. Analiz sonucu oluşturulan yorum ve müzik önerileri saklanabilir.

4. Müzik Öneri Özelliği

Uygulama aşağıdaki servisleri kullanır:

  • Apple iTunes Search API
  • Spotify (harici bağlantı)
  • YouTube (harici bağlantı)

5. Kimlik Doğrulama

Uygulama ASP.NET Core JWT kimlik doğrulama sistemini kullanır.

Cihazda saklanan bilgiler:

  • Access token
  • Kullanıcı ID
  • E-posta

6. Veri Saklama

Veriler hesap aktif olduğu sürece saklanır. Hesap silme sonrası veriler 30 gün içinde tamamen silinir.

7. Analitik

Aklımda uygulaması herhangi bir analitik servisi kullanmaz.

8. Altyapı

  • Backend: Render
  • Veritabanı: Supabase PostgreSQL

9. Güvenlik

Veriler HTTPS, JWT ve hashlenmiş parolalar ile korunur.

10. Çocukların Gizliliği
